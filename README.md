# ✅ To-Do Manager (Haskell • Functional Programming Project)

Një aplikacion i zhvilluar në Haskell duke përdorur parimet bazë dhe të avancuara të **programimit funksional**, me CLI interaktive, filtër funksional, raportim, eksport JSON/HTML dhe një **DSL të avancuar** për manipulimin e detyrave.

Ky projekt është realizuar si pjesë e kursit të Programimit Funksional.

# ⚙️ Instalimi & Ekzekutimi

### ✅ Kërkesat
- **GHC 9.x**
- **Cabal**
- **Windows/Linux/MacOS terminal**

### ✅ Instalimi
Clono projektin:

```bash
git clone https://github.com/bardhideveloper/todo-manager.git
cd todo-manager

Ndërto projektin:
cabal build

Ekzekutimi:
cabal run
